# PRISM — Predictive Risk Identification of Sepsis with Machine Learning

LSTM-based framework for **early sepsis prediction** on two clinical cohorts
(SepsisExp and MIMIC-III), with an exploratory data-analysis stage, a training/testing
pipeline, and a REST inference API.

> **In breve (IT):** framework LSTM per la predizione precoce della sepsi su SepsisExp
> e MIMIC-III. Tre moduli: (1) analisi dati, (2) training/testing, (3) API di
> inferenza. Segui la guida passo-passo qui sotto.

---

## Repository layout / Struttura

```
ml-prism/
├── statistics/   # 1) data study & analysis (pre-model)      -> statistics/README.md
├── model/        # 2) LSTM training & testing (PyTorch)      -> model/README.md
├── backend/      # 3) REST inference API (Flask)             -> backend/README.md
├── models/       # trained .pth checkpoints (small, committed)
├── datasets/     # raw training data (~1.6 GB, NOT committed) -> datasets/README.md
└── scripts/      # prepare_data.sh (fetch/build the datasets)
```

The three modules are independent and can be used on their own; the typical flow is
`statistics → model → backend`.

## Step-by-step / Guida passo-passo

### 0. Prerequisites / Prerequisiti
- Python **3.10+** (3.11 recommended).
- A virtual environment (conda or `venv`).
- GPU (CUDA) is optional but strongly recommended for training; CPU works too.

### 1. Install dependencies / Installa le dipendenze
```bash
python -m venv .venv && source .venv/bin/activate     # or: conda create -n prism python=3.11

# common deps (statistics + model)
pip install -r requirements.txt

# PyTorch + CUDA (training) — pick the wheel for your CUDA version
pip install -r requirements-torch.txt
# (CPU-only alternative: pip install torch --index-url https://download.pytorch.org/whl/cpu)

# inference API (only if you will run the backend)
pip install -r backend/requirements/requirements-api.txt
```

### 2. Get the data / Ottieni i dati
The raw datasets (~1.6 GB) are **not** in git. Create the layout and fetch them:
```bash
bash scripts/prepare_data.sh
```
- **SepsisExp** is public (CC-BY 4.0) — see `datasets/README.md`.
- **MIMIC-III** requires credentialed PhysioNet access — see `datasets/README.md`.

### 3. (Optional) Exploratory analysis / Analisi esplorativa
```bash
python statistics/load_mimic.py      # MIMIC: build processed arrays
python statistics/data_analysis.py   # SepsisExp/MIMIC: clustering, SHAP, PFI, ...
```
See `statistics/README.md`.

### 4. Train the model / Addestra il modello
Edit the configuration at the top of the `__main__` block in `model/ML_Prism.py`
(dataset, `target_len`, `pred_length`, `method`), then:
```bash
python model/ML_Prism.py
```
Checkpoints are written to `models/`. See `model/README.md`.

### 5. Run the inference API / Avvia l'API di inferenza
```bash
cd backend
docker compose up -d          # recommended
# or locally:
python start_api.py           # -> http://localhost:5000  (Swagger: /apidocs)
```
Place your trained `.pth` files in `backend/models/` (see `backend/README.md`); without
them the API still starts but uses a mock predictor.

---

## Notes / Note
- The `backend/datasets/` JSON files (normalization/scaler stats) **are** committed —
  they are required by the API and are tiny. Only the large `datasets/` training data is
  excluded.
- Outputs (`clustering/`, `trees/`, loss curves, `*.csv` reports) are gitignored and
  regenerated by the scripts.
- Reference: see the companion paper and the Zenodo archive (see `Declarations` in the
  manuscript) for the full method description.
